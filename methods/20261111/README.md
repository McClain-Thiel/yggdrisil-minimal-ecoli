## Exact source and data recovery

[manifest.json](manifest.json) maps every deployed source path to a Git file and exact SHA256. Identical source bytes reuse an earlier frozen snapshot; changed versions live under `runtime/`. The original [search](search-deployment-manifest.json), [primary validation](primary-deployment-manifest.json) and [secondary validation](secondary-deployment-manifest.json) manifests also record input/configuration identities. Source snapshots are historical records, not instructions to run science locally. The current maintained entry points may evolve independently.

The data catalog maps search IDs and genotype hashes to individual outcomes. Its final search archive contains all ten graphs, inputs and closures. Three immutable validation checkpoint indexes locate individual content-addressed data objects; two final worker archive indexes give complete member inventories and hashes. Some checkpoint metadata differs from the later final archive: both versions remain available. Use the exact S3 URI, byte count and SHA256 rather than an ETag. S3 and W&B access require the authorized research account; no credentials or signed transfer links are included.

Independent verification used full S3 downloads and uncached committed W&B downloads for both final archives and checked every indexed member. Final checkpoint verification reused prior full-download proofs only for byte-identical immutable references with matching W&B manifest entries; changed entries were downloaded again. The [data catalog](../../experiments/comparisons/depth-matched-data-index-20261111.json) links full proofs. Deallocation occurred after those checks; both dedicated disks are gone and shared compute was untouched.

The `analysis/` files preserve the original summary and verification implementations, including their historical execution paths. For a portable figure rebuild from public compact metadata, run `python scripts/plot_depth_matched_comparison.py --output /tmp/depth-matched` from the repository. The public JSON and CSV contain all 25 nominated-search rows and retain shared-genotype identities and inconclusive outcomes.

This follow-up is exploratory: selection and early stopping were amended after observing search depth, and it does not provide an equal-realized-budget or perfectly depth-matched superiority test. Its purpose is to distinguish cheap-gate success from sustained whole-cell division at substantially deeper baseline reductions.
